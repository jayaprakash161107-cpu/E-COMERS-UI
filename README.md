# React E-Commerce UI

A modern and responsive E-Commerce User Interface built using **React.js, JavaScript, HTML, and CSS**.

This project displays products in an attractive card layout and allows users to add or remove products from their cart. It focuses on React components, state management, responsive design, and user interaction.

## Features

- Responsive product card layout
- Display products with images, names, and prices
- Add to Cart functionality
- Remove from Cart functionality
- Dynamic cart item counter
- React state management using `useState`
- Reusable React components
- Modern CSS styling, hover effects, and gradients
- Mobile-friendly layout using media queries

## Technologies Used

- **React.js** – Building reusable UI components
- **JavaScript (ES6+)** – Application logic and functionality
- **HTML5** – Webpage structure
- **CSS3** – Styling and responsive design
- **Git & GitHub** – Version control

## Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/jayaprakash161107-cpu/E-COMERS-UI.git
```

### 2. Open the Project Folder

```bash
cd E-COMERS-UI
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Run the Project

```bash
npm run dev
```

Open the local URL displayed in your terminal to view the application.

## How It Works

1. Products are displayed using reusable React components.
2. Each product card contains an image, name, price, and cart button.
3. Users can add products to their cart.
4. Users can remove products from their cart.
5. The cart counter updates dynamically using React's `useState` hook.
6. CSS Grid and media queries make the design responsive.
